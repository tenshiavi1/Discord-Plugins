# Sage Eyes

Sage Eyes is a Revenge mobile plugin by tenshiavi for showing and inspecting hidden or obscured channels in the client.

## Features

- Shows hidden-channel names that are available to the client but omitted or obscured by Discord's interface.
- Optionally marks hidden channel names with a lock icon.
- Optionally prompts before opening a hidden channel and displays available channel information.

The plugin changes client-side visibility and navigation behavior; it does not grant server permissions or guarantee access to channel messages.

## Settings

- **Show Lock Icon** controls the hidden-channel indicator.
- **Show Popup on Hidden Channels** controls the confirmation and information popup before opening a hidden channel.

## Source

Plugin metadata is in `manifest.json`; implementation is in `src`.
