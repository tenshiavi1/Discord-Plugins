# Vencord Plugins

This folder is for desktop Vencord plugins and their project-specific documentation.

Vencord plugins use a different runtime and build process from Revenge mobile plugins. They are intentionally excluded from the root Revenge plugin build and GitHub Pages integration bundles. Add each Vencord plugin here with its own source, README, and any required Vencord-compatible build or contribution instructions.

No Vencord plugins have been added to this folder yet.
